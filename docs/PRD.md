# PRD: 전생서랍 Phase 1 MVP

## 목표
Instagram Reels 유입 사용자가 로그인 없이 전생 테스트를 완료하고, 생년월일 기반 성향 요약으로 신뢰를 얻은 뒤 전생 기록을 하나씩 열어보고 싶게 만드는 모바일 우선 웹서비스를 만든다.

## 사용자
- 국내 20~30대 여성 중심
- 사주/타로/심리테스트류 콘텐츠에 익숙하지만 촌스러운 무속 이미지는 부담스러워하는 사용자
- 짧은 시간 안에 재미와 개인화 느낌을 원하는 모바일 광고 유입 사용자

## 브랜드 컨셉
- 화면 제목은 `전생 서랍`으로 띄어 써서 더 부드럽고 감성적인 인상을 준다.
- 제품 개념은 오래된 나의 기록이 작은 서랍 안에 보관되어 있고, 사용자가 하나씩 열어보는 경험이다.
- 첫 결과는 곧바로 전생을 단정하기보다 "생년월일과 답변 패턴을 보면 당신은 이런 결을 가진 사람입니다"라는 짧은 성향 요약으로 시작한다.
- 그 다음 "이 결이 가장 강하게 이어진 전생 기록"을 추천해 신뢰와 호기심을 연결한다.
- 톤은 예전 연한 갈색, 노란빛 종이, 오래된 목재 서랍을 떠올리게 하되 촌스럽거나 점집처럼 보이지 않게 세련된 모바일 콘텐츠로 정리한다.

## 핵심 기능
1. 랜딩에서 바로 무료 테스트 시작
2. 닉네임, 생년월일, 선택 출생시간, 7개 직관형 질문 입력
3. 입력 정규화 후 동일 입력에 대해 동일 `Soul ID`와 동일 `SoulProfile` 생성
4. 생년월일 기반 성향 요약 3~4줄을 먼저 표시
5. 대표 전생 기록 1개와 희미한 추가 기록 2개를 무료 결과로 표시
6. 잠긴 기록 목록을 보여주고 결제/로그인 필요 흐름으로 유도
7. 결과 조회는 긴 `result_token` 또는 세션 소유권으로만 허용
8. 이벤트 수집 구조를 준비한다.

## 무료 결과 범위
- 공개: 생년월일 기반 성향 요약, 대표 전생의 위치, 직업, 짧은 분위기
- 티저: 희미한 추가 기록 2개는 제목과 아주 짧은 단서만 표시
- 비공개: 사랑, 죽음, 업보, 반복 감정, 두 번째 기록의 상세 내용

## MVP 제외 사항
- 실제 PG 결제 승인
- 실제 로그인/회원가입
- Soul balance 충전과 유료 콘텐츠 unlock
- 공유 이미지 생성
- 추천 보상
- 관리자 대시보드
- 음력 변환, 정통 만세력, 출생지 기반 세밀 계산

## 디자인
- 모바일 우선
- 세련되고 담백한 전생 기록 앱
- 화면 첫 인상은 `전생 서랍`이라는 제목과 오래된 서랍을 여는 듯한 질감으로 잡는다.
- 색감은 연한 갈색, 바랜 노란 종이, 아이보리, 차분한 목재색을 중심으로 한다.
- 무속, 부적, 과한 금색, 저가 운세 사이트 이미지를 피한다.
- 너무 밝거나 유치한 톤보다 고즈넉하고 따뜻한 배경, 절제된 잉크색 텍스트, 작은 황동색 포인트를 사용한다.

## 성공 기준
- 모바일에서 랜딩부터 결과까지 막힘 없이 진행된다.
- 같은 입력을 반복 제출해도 같은 핵심 결과가 나온다.
- 새로고침으로 결과가 재생성되지 않는다.
- 잠긴 콘텐츠 클릭 시 결제 전환 의도가 명확하게 생긴다.
