# UI 디자인 가이드

## 디자인 원칙
1. 모바일에서 첫 화면, 질문, 결과, 잠긴 기록이 한 손 조작으로 이어져야 한다.
2. 전생이라는 소재는 쓰되 무속, 부적, 점집, 과한 금색 이미지는 피한다.
3. 담백한 문장과 세련된 여백으로 20~30대 여성이 Instagram에서 들어와도 부담 없이 느끼게 한다.
4. 화면 제목은 `전생 서랍`으로 표기하고, 오래된 서랍에서 기록을 하나씩 꺼내 보는 경험을 중심에 둔다.
5. 첫 결과는 전생 단정보다 생년월일 기반 성향 요약으로 신뢰를 만든 뒤, 그 성향과 이어진 대표 전생을 보여준다.

## 컨셉
```text
전생 서랍
오래된 나의 기록이 작은 서랍 안에 보관되어 있고,
사용자는 무료로 첫 번째 서랍을 열어본 뒤 더 깊은 기록을 하나씩 연다.
```

핵심 감각:

- 예전 연한 갈색 종이
- 바랜 노란빛
- 오래된 목재 서랍
- 조용한 기록 보관소
- 모바일에서 세련되게 정리된 감성 콘텐츠

피해야 할 방향:

- 무속집, 부적, 점집, 과한 금색
- 지나치게 어두운 오컬트 분위기
- 보라색 AI 템플릿 느낌
- 귀엽기만 한 다이어리 앱 느낌

## AI 슬롭 안티패턴
| 금지 사항 | 이유 |
|-----------|------|
| 과한 보라/인디고 그라데이션 | AI SaaS 템플릿처럼 보인다. |
| 부적, 금박, 별자리 과다 장식 | 촌스럽거나 무속적으로 보인다. |
| "Powered by AI" 강조 | 사용자가 사는 것은 기술이 아니라 결과다. |
| 네온 글로우와 둥근 카드 남발 | 저가 랜딩 페이지 느낌이 난다. |
| 장황한 설명 섹션 | 광고 유입 사용자는 바로 테스트를 원한다. |
| 과한 낡은 종이 텍스처 | 빈티지 카페 메뉴판처럼 보일 수 있다. |

| 용도 | 값 |
|------|------|
| 페이지 배경 | `#F5E8C8` |
| 보조 배경 | `#EFE0B8` |
| 카드/패널 | `#FFF7E3` |
| 서랍 내부면 | `#E4C98F` |
| 주 텍스트 | `#2E2418` |
| 본문 | `#5F4A32` |
| 보조 텍스트 | `#8A7352` |
| 라인 | `#D4B77A` |
| 포인트 | `#8F5A2A` |
| 보조 포인트 | `#B8873E` |
| 잉크 포인트 | `#263238` |
| 성공/완료 | `#6F8A65` |
| 오류 | `#B45A3C` |

사용 원칙:

- 전체 배경은 따뜻한 종이색으로 둔다.
- 카드/패널은 종이보다 조금 밝게 해서 읽기 쉽게 만든다.
- CTA는 진한 목재색 또는 황동색 계열을 사용한다.
- 금색은 포인트로만 쓰고 광택, 번쩍임, 금박 효과는 피한다.
- 어두운 색은 텍스트와 작은 라벨에만 사용한다.

## 컴포넌트
### 버튼
```text
Primary: rounded-lg, deep wood background, warm paper text
Secondary: transparent/warm paper surface, muted brown border
Icon: lucide icon + accessible label
```

### 입력 필드
```text
rounded-lg bg-[#FFF7E3] border border-[#D4B77A] px-4 py-3
focus ring은 muted brass 계열
```

### 결과 카드
```text
rounded-lg, border 1px, 과한 shadow 없음
반복 카드만 card로 사용하고 섹션 전체를 카드처럼 감싸지 않는다.
기록 카드는 서랍 라벨처럼 작은 번호, 시대, 위치, 역할을 명확히 보여준다.
잠긴 기록은 닫힌 서랍처럼 보이되, 클릭 가능한 콘텐츠 제목이 먼저 보여야 한다.
```

### 성향 요약 패널
```text
무료 결과 최상단에 배치한다.
"당신은 ~~한 사람입니다"로 시작하되 운명 단정이 아니라 성향 해석으로 쓴다.
3~4줄 이내로 유지하고, 전생 추천의 근거 역할만 한다.
```

## 레이아웃
- 기본 폭: 모바일 `max-w-md`, 데스크톱은 중앙 고정
- 첫 화면은 테스트 CTA가 viewport 안에 보여야 한다.
- 결과 페이지는 `성향 요약 → 전생 서랍 열림률 → 대표 기록 → 잠긴 기록` 순서로 스크롤한다.
- 첫 화면에는 실제 서랍, 종이 라벨, 열린 틈 같은 시각 단서가 있어야 한다.
- 잠긴 콘텐츠가 너무 아래로 밀리지 않도록 대표 기록은 짧고 밀도 있게 보여준다.
